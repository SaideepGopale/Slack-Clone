🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: Backend not connecting
  → Solution: Check PORT=4000 in backend/.env
  → Check proxy in frontend/vite.config.ts
  → Restart both servers

Problem: All logins failing
  → Solution: Run: cd backend && npm run seed
  → Test with: test@example.com / password123

Problem: Admin panel not accessible
  → Solution: Login as admin@slack.com
  → Verify email contains @admin
  → Check admin status in database

Problem: Messages not syncing
  → Solution: Check browser DevTools → Network → WS
  → Verify Socket.IO connection established
  → Restart backend server

Problem: Database connection error
  → Solution: Check DATABASE_URL in backend/.env
  → Verify PostgreSQL is running
  → Check connection string format
