## 📊 Styling Details

### Typography
- **Titles**: Bold, 28-32px, dark gray
- **Subtitles**: Medium, 14px, medium gray
- **Labels**: Semibold, 12px, uppercase, tracking-wide
- **Body**: Regular, 14px, dark gray

### Borders & Shadows
- **Borders**: 1px solid light gray (#E5E7EB)
- **Shadows**: Subtle `shadow-sm` (0 1px 2px rgba(0,0,0,0.05))
- **Hover Shadows**: Slightly elevated `shadow-md`
- **Border Radius**: 8px for inputs, 6px for badges

### Spacing
- **Padding**: 8px (2), 16px (4), 24px (6), 32px (8)
- **Gaps**: 12px (3), 16px (4), 20px (5)
- **Margins**: Consistent spacing throughout

### Interactions
- **Hover**: Background color shift, shadow elevation
- **Focus**: Blue ring (2px), light blue background
- **Active**: Solid blue background with border
- **Loading**: Animated dots with blue color
- **Disabled**: 50% opacity with cursor-not-allowed

## 📞 How to Use

### Access Admin Panel
1. Log in with admin email (contains `@admin`)
2. Click admin icon in header
3. You'll see the white-themed admin panel

### View Metrics
1. Go to Dashboard tab
2. See all stats at top
3. View online users on right side

### Manage Users
1. Go to User Management tab
2. Search by name/email
3. Click user to see details
4. Hover to see ban/delete buttons

### Manage Channels
1. Go to Channel Management tab
2. Search for channels
3. Click "New Channel" to create
4. Hover and click delete to remove
5. Click to see channel details
