🔄 ARCHITECTURE
════════════════════════════════════════════════════════════════════════════════

User Interface:
  Users click status button → Emit via Socket.IO → Backend receives
  
Backend Processing:
  Receive 'user:status' event → Update onlineUsers Map → Broadcast to ALL clients
  
Real-Time Broadcast:
  Backend emits 'user:online' to all connected clients with updated user list
  
Frontend Updates:
  Header shows user's own status → Admin panel shows all users with status
  

📡 WEBSOCKET EVENTS
════════════════════════════════════════════════════════════════════════════════

FROM FRONTEND TO BACKEND:
socket.emit('user:status', {
  status: 'active' | 'away' | 'in_meeting',
  emoji: '🟢' | '🟡' | '🔴'
})

FROM BACKEND TO ALL CLIENTS:
socket.on('user:online', [
  { id: 'user-id', username: 'name', status: 'active', emoji: '🟢' },
  { id: 'user-id', username: 'name', status: 'away', emoji: '🟡' },
  ...
])
